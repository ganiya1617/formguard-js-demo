# FormGuard JS Demo

A quick demonstration project showing the features and capabilities of the [`@ganiya1617/formguard-js`](https://www.npmjs.com/package/@ganiya1617/formguard-js) npm package.

## Features Demonstrated

- **Multi-Field Validation**: Validating multiple form inputs simultaneously.
- **Schema-Based Validation**: Clean, declarative schema definitions for form inputs.
- **Individual Validators**: Direct usage of `isEmail`, `isPhone`, `isRequired`, `checkLength`, and `checkPassword`.
- **Password Strength Assessment**: Calculating password strength scores and checking rule compliance.
- **Custom Rules**: Defining and executing custom validation logic via `addRule()`, `validateWith()`, and `validateField()`.

## Installation

```bash
npm install
```

## Running the Demo

```bash
npm start
```
